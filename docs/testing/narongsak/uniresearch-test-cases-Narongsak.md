## 1. บทนำ

ฉบับเฉพาะ Narongsak: คัด 18 กรณีที่จัดสรรให้ Narongsak จากชุดหลัก 48 กรณี ครอบคลุม 17 FR รายละเอียดและสถานะอ้างอิงชุดทดสอบอัตโนมัติ Selenium + Pytest โดยใช้ข้อมูลจริงจาก `student.csv`, `advisors.csv` และชื่องานวิจัยภาษาไทยจาก `migrate.py` บนฐานข้อมูลทดสอบแยก

### 1.1 สภาพแวดล้อมการทดสอบ

### 1.2 เกณฑ์การผ่าน

กรณีผ่านเมื่อผลจริงตรงทุกข้อที่คาดหวัง และมีหลักฐานตรวจซ้ำได้ กรณีเชิงลบต้องส่งคำขอตรงถึง API และตรวจว่าไม่มีการเปลี่ยนข้อมูลที่ไม่ควรเปลี่ยน สำหรับหน้าที่มี UI ให้ตรวจ UI/redirect เพิ่มด้วย หาก UI กับ API ให้สิทธิ์ต่างกัน ให้บันทึกตามผลจริงและเปิด defect/ข้อสงสัย
