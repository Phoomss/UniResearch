# Backend endpoint inventory

All documented success codes are 200 because no route sets another `status_code`. `422` is FastAPI request validation. Runtime-only errors are listed separately. “Bearer” means an active user is required.

| Method | Path | Auth / role | Request | Parameters | Response / success | Errors evidenced | Tests |
|---|---|---|---|---|---|---|---|
| GET | `/` | Public | None | None | `{message: string}` / 200 | None declared | None |
| POST | `/auth/register` | Public | JSON `UserCreate`: `email`, `password`, optional `role`, `student_id`, `department`, `first_name`, `last_name` | None | `UserResponse` / 200 | 400 duplicate email; 422 validation | Registration success only |
| POST | `/auth/login` | Public | `application/x-www-form-urlencoded`: required `username`, `password`; optional `scope`, `client_id`, `client_secret` from OAuth form | None | `Token` / 200 | 400 incorrect credentials; 422 form validation | Success; wrong password |
| POST | `/categories/` | Bearer; `admin` | JSON `CategoryCreate`: `category_name`, optional `description` | None | `CategoryResponse` / 200 | 400 inactive; 401 invalid/missing token; 403 role; 422 validation; duplicate may be unhandled 500 | Indirect success in research tests |
| GET | `/categories/` | Public | None | None | `CategoryResponse[]` / 200 | None declared | None |
| POST | `/research/` | Bearer; `admin` or `student` | `multipart/form-data`; exact fields: required text `title_th`, `title_en`, integer `category_id`; optional `abstract`, `department`, `work_type`, integer `academic_year`, `keywords`, JSON-string `author_ids` default `[]`, JSON-string `advisor_ids` default `[]`, file `cover_image`, file `document` | None | `ResearchWorkResponse` / 200 | 400 inactive; 401; 403; 422; malformed ID JSON, FK/file failures may be 500 | Admin minimal create; no files/authors/advisors |
| GET | `/research/search` | Public | None | Query `q?: string`, `category_id?: integer` | `ResearchWorkResponse[]` / 200 | 422 invalid category ID; DB/log failures may be 500 | Query by English title after admin approval; category filter not asserted |
| GET | `/research/{research_id}` | Public | None | Path `research_id: integer` | `ResearchWorkResponse` / 200 | 404 `{detail:"Not found"}`; 422 invalid ID | None |
| POST | `/research/{research_id}/download` | Bearer; any active role | None | Path `research_id: integer` | Unspecified object, runtime `{file_url:string}` / 200 | 400 inactive; 401; 404 `{detail:"File not found"}`; 422 | None |
| POST | `/research/{research_id}/review` | Bearer; `advisor` or `admin` | JSON `ReviewCommentCreate`: `comment_text`, `status_result` | Path `research_id: integer` | `ReviewCommentResponse` / 200 | 400 inactive; 401; 403; 404 `{detail:"Not found"}`; 422 | Admin approval only |
| POST | `/favorites/{research_id}` | Bearer; any active role | None | Path `research_id: integer` | Add: `FavoriteResponse`; remove: `{detail:string}`; both 200 | 400 inactive; 401; 422; FK failures may be 500 | None |
| GET | `/favorites/` | Bearer; any active role | None | None | `FavoriteResponse[]` / 200 | 400 inactive; 401 | None |
| GET | `/stats/` | Public | None | None | `{total_users,total_research_works,total_views,total_downloads}` integers / 200 | None declared | None |
| GET | `/home/latest` | Public | None | Query `limit: integer = 5` (no bounds) | `ResearchWorkResponse[]` / 200 | 422 invalid integer | None |
| GET | `/home/popular` | Public | None | Query `limit: integer = 5` (no bounds) | `ResearchWorkResponse[]` / 200 | 422 invalid integer | None |

Non-contract routes: `GET /docs` redirects (307) to `/swagger`; `GET /swagger` returns HTML; `GET /openapi.json` is generated by FastAPI; `/static/*` serves files from disk.

There are no endpoints for logout, refresh, current user/profile, forgot/reset password, email verification, OAuth, users/authors/advisors lookup, update/delete research, submission lists, reviewer queues, revisions, review history, direct binary download, notifications, citations, or popular search terms.
