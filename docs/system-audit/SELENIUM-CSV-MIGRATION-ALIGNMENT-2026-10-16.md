# ผลปรับสคริปต์ Selenium ให้ตรงเอกสารและข้อมูล CSV/migration

วันที่ 16 ตุลาคม 2026 · เอกสาร Markdown และสคริปต์ Python · ไม่สร้าง Word/PDF

ปรับ fixture และกรณีทดสอบให้ใช้ชื่อ อีเมล รหัสนักศึกษา และภาควิชาจาก CSV พร้อมชื่องานและ metadata จาก migration แล้วรันแอปจริงบน localhost ด้วย Chrome headless ฐานทดสอบเป็น SQLite ชั่วคราวและ AI เป็น deterministic mock

ผลรอบเต็ม C16 คือ **43 PASS / 5 FAIL จาก 48 กรณี** พบปัญหาสคริปต์ใน TC-015/032 และแก้พร้อมทวนผ่านใน R16; เพิ่ม UI ของ TC-002/012/015 และทวน TC-005 ด้วย R16 ได้ **4 PASS / 1 FAIL** โดย TC-002 คาดข้อความภาษาอังกฤษแทนข้อความภาษาไทยของเว็บ จากนั้นแก้จุดตรวจและทวน TC-002 ใน R16B ได้ **1 PASS** ทั้งสามรอบแยกกัน ไม่รายงานเป็น 45/48 PASS ใน session เดียว

ยังมีข้อผิดพลาดระบบ **TC-018, TC-027 และ TC-045** ไม่เปลี่ยน expected status เป็น 500 ไม่ skip และไม่แก้ business logic เพื่อทำผลให้ผ่าน

## สิ่งที่ปรับ

- [`dataset.py`](../../tests/selenium/dataset.py) อ่านเฉพาะข้อมูลระบุตัวตนจาก `student.csv`/`advisors.csv`; ไม่ใช้คอลัมน์รหัสผ่าน อ่านค่าคงที่ของ `migrate.py` ด้วย AST โดยไม่ execute migration
- ใช้บัญชี `674259009@webmail.npru.ac.th`, `674259003@webmail.npru.ac.th`, `644259003@webmail.npru.ac.th`, `udsanee@webmail.npru.ac.th`, `wuttha@webmail.npru.ac.th` และชื่อจริงตาม CSV บัญชีผู้ดูแล/guest เป็นข้อมูลสำหรับฐานทดสอบ; ตั้ง inactive เฉพาะสำเนาบัญชีที่เอกสารระบุ
- ใช้ชื่องานเต็มทั้งสี่เรื่องและสำเนาที่มีคำอธิบายท้ายชื่อ ตาม [ข้อมูลวิจัย](TEST-RESEARCH-DATA.md) ใช้ชื่ออังกฤษ บทคัดย่อ คำสำคัญ หมวดหมู่ ประเภทงาน ภาควิชา และปีจากเรื่องเดียวกัน
- รหัสผ่านเฉพาะสำเนาฐานทดสอบคือ `UniResearchTest2026!`; `TEST_PASSWORD` override ได้ โดยต้องบันทึกว่าต่างจากคู่มือ ไม่ทดสอบรหัสผ่านจริงของบัญชีต้นทาง
- ขั้นตอนสำคัญเดินผ่านเมนูและแถวงานจริง: สมัครสมาชิก ส่งงานห้าขั้น แก้ไขงาน เอกสารทั้งหมด → ตรวจสอบ → สถานะ → ยืนยัน เปิดผลตรวจและแจ้งเตือนของผู้เขียนแต่ละคน
- เพิ่มการตรวจข้อมูลสัมพันธ์ผิดรูปแบบ ขอบเขตไฟล์ต่ำกว่า/เท่ากับ/เกิน limit rollback ของไฟล์เดิม revision เริ่มที่ 1/การแก้ metadata อย่างเดียว ความเห็นและแจ้งเตือนครบสามสถานะ การมอบหมายที่ปรึกษา และแจ้งเตือนสองรายการของผู้ใช้เดียวกัน
- ชื่อและผลคาดหวังทั้ง 48 กรณีใน `cases.json` ตรงกับ Test Cases รายงานแยก UI จริงจาก API-only และแยก NOT RUN จากผลย้อนหลัง
- `--all-cases` เลือกครบ 48; ค่าเริ่มต้นยังเป็น 18 ของ Narongsak; `--include-legacy` เป็นชื่อทางเลือกของ flag เดียวกัน
