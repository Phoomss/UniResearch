# แหล่งข้อมูลชื่องานวิจัยสำหรับเอกสารทดสอบ

ทบทวน 16 ตุลาคม 2026: อ่าน `research_papers` ด้วยการตรวจ source โดยไม่ได้รัน migration หรือเชื่อมต่อฐานข้อมูล ชื่อภาษาไทย/อังกฤษทั้ง 4 เรื่องตรงกันใน [migrate.py](../../backend/app/scripts/migrate.py) และ [seed_thai_data.py](../../backend/app/scripts/seed_thai_data.py)

สคริปต์ [unified_seed_migrate.py](../../backend/app/scripts/unified_seed_migrate.py) เตรียมตัวเลือก ผู้ดูแล และนำเข้า CSV ผู้ใช้ ไม่ได้ประกาศรายการผลงาน 4 เรื่องนี้ ส่วน [student.csv](../../backend/app/scripts/student.csv) และ [advisors.csv](../../backend/app/scripts/advisors.csv) เป็นแหล่งชื่อ/อีเมลของบุคคล ไม่มีคอลัมน์ชื่องานวิจัย

## รายการตามต้นทาง

คำว่า “ชื่องานจริง” ในเอกสารหมายถึงชื่อที่มีอยู่จริงในสคริปต์ของโครงการ สคริปต์เรียกข้อมูลนี้ว่า mock research works จึงไม่ใช้ยืนยันว่าเป็นผลงานตีพิมพ์หรือเป็นผลงานของบุคคลใน CSV จริง

### 1. การพัฒนาระบบแนะนำหัวข้อโครงงานวิจัยอัตโนมัติโดยใช้ปัญญาประดิษฐ์

**ชื่อภาษาอังกฤษ:** Development of an Automatic Research Topic Recommendation System using Artificial Intelligence

**หมวดหมู่:** วิทยาการคอมพิวเตอร์และปัญญาประดิษฐ์ · **ภาควิชา:** วิทยาการคอมพิวเตอร์ · **ประเภท:** วิทยานิพนธ์ · **ปี:** 2568

**คำสำคัญ:** ปัญญาประดิษฐ์, ระบบแนะนำ, การประมวลผลภาษาธรรมชาติ, โครงงานวิจัย

**บทคัดย่อ:** งานวิจัยนี้นำเสนอการพัฒนาระบบแนะนำหัวข้อโครงงานวิจัยวิศวกรรมคอมพิวเตอร์และปัญญาประดิษฐ์อัตโนมัติ สำหรับนักศึกษาและอาจารย์ เพื่อเป็นตัวช่วยในการค้นหาแนวทางการตั้งโจทย์วิจัยที่เหมาะสม โดยการวิเคราะห์ข้อมูลความสนใจ ทักษะ และประวัติการทำโครงงานก่อนหน้าของผู้ใช้งาน ระบบใช้โมเดลโครงข่ายประสาทเทียมลึก (Deep Neural Networks) ในการประมวลผลภาษาธรรมชาติของบทคัดย่อภาษาไทยและภาษาอังกฤษ ผลสัมฤทธิ์พบว่ามีความถูกต้องในการแนะนำหัวข้อที่ผู้ใช้พึงพอใจสูงถึงร้อยละ 87.5

**บัญชีใน migrate.py:** ผู้ส่ง `student1@uniresearch.ac.th`; ผู้เขียน `student1@uniresearch.ac.th`; ที่ปรึกษา `advisor1@uniresearch.ac.th`; ผลตรวจ `approved`

### 2. การศึกษาประสิทธิภาพของโมเดลการประมวลผลภาษาธรรมชาติบนสถาปัตยกรรมหม้อแปลงสำหรับการจัดหมวดหมู่งานวิจัยภาษาไทย

**ชื่อภาษาอังกฤษ:** Performance Evaluation of Transformer-based NLP Models for Thai Research Document Classification

**หมวดหมู่:** วิทยาการคอมพิวเตอร์และปัญญาประดิษฐ์ · **ภาควิชา:** วิศวกรรมคอมพิวเตอร์ · **ประเภท:** วิทยานิพนธ์ · **ปี:** 2567

**คำสำคัญ:** การประมวลผลภาษาธรรมชาติ, สถาปัตยกรรมหม้อแปลง, การจัดหมวดหมู่เอกสาร, ภาษาไทย

**บทคัดย่อ:** เอกสารวิจัยนี้นำเสนอการประเมินและเปรียบเทียบประสิทธิภาพของสถาปัตยกรรมโมเดล Transformer ประเภทต่างๆ เช่น WangchanBERTa และ Multilingual BERT ในการทำความเข้าใจและคัดแยกหมวดหมู่เอกสารงานวิจัยวิชาการภาษาไทย ผลการทดลองบนคลังข้อมูลขนาด 5,000 ชิ้นแสดงให้เห็นว่าการปรับจูนไฮเปอร์พารามิเตอร์แบบกำหนดเองให้ผลลัพธ์ที่มีคะแนน F1-score สูงถึง 91.2% ซึ่งเป็นประโยชน์อย่างมากต่อการนำไปใช้งานในคลังห้องสมุดดิจิทัลแบบอัตโนมัติ

**บัญชีใน migrate.py:** ผู้ส่ง `student2@uniresearch.ac.th`; ผู้เขียน `student2@uniresearch.ac.th`; ที่ปรึกษา `advisor2@uniresearch.ac.th`; ผลตรวจ `approved`

### 3. การออกแบบตัววัดเซ็นเซอร์แบบประหยัดพลังงานสำหรับระบบเกษตรอัจฉริยะในพื้นที่ห่างไกล

**ชื่อภาษาอังกฤษ:** Energy-Efficient Sensor Design for Smart Agriculture in Remote Areas

**หมวดหมู่:** วิศวกรรมศาสตร์และนาโนเทคโนโลยี · **ภาควิชา:** วิทยาการคอมพิวเตอร์ · **ประเภท:** โครงงานวิจัย · **ปี:** 2568

**คำสำคัญ:** เกษตรอัจฉริยะ, พลังงานต่ำ, เซ็นเซอร์, LoRaWAN

**บทคัดย่อ:** โครงงานนี้นำเสนอแนวทางการออกแบบตัวประมวลผลและเซ็นเซอร์วัดความชื้นในดินและอุณหภูมิที่ทำงานโดยใช้พลังงานต่ำมาก (Ultra-low power) เพื่อใช้กับระบบฟาร์มอัจฉริยะในท้องถิ่นชนบทห่างไกลที่ไม่มีไฟฟ้าและสัญญาณอินเทอร์เน็ตที่เสถียร โดยส่งสัญญาณผ่านโปรโตคอล LoRaWAN ทำให้แบตเตอรี่หนึ่งก้อนสามารถใช้งานได้ยาวนานเกิน 3 ปี

**บัญชีใน migrate.py:** ผู้ส่ง `student1@uniresearch.ac.th`; ผู้เขียน `student1@uniresearch.ac.th`; ที่ปรึกษา `advisor1@uniresearch.ac.th`; ผลตรวจ `approved`

### 4. การพัฒนาคลังความรู้ดิจิทัลเพื่อการสืบค้นงานวิจัยทางการศึกษาของสถาบันอุดมศึกษา

**ชื่อภาษาอังกฤษ:** Development of a Digital Repository for Educational Research in Higher Education Institutions

**หมวดหมู่:** เทคโนโลยีการศึกษาและนวัตกรรมการเรียนรู้ · **ภาควิชา:** วิศวกรรมคอมพิวเตอร์ · **ประเภท:** วิทยานิพนธ์ · **ปี:** 2568

**คำสำคัญ:** คลังความรู้ดิจิทัล, ผลงานวิจัยทางการศึกษา, การจัดการความรู้

**บทคัดย่อ:** การวิจัยครั้งนี้มีวัตถุประสงค์เพื่อพัฒนาแพลตฟอร์มคลังความรู้ดิจิทัลสำหรับรวบรวมและเปิดให้ดาวน์โหลดผลงานวิจัยนวัตกรรมการเรียนรู้ของบุคลากรทางการศึกษา ระบบมีส่วนช่วยในการแบ่งปันและแลกเปลี่ยนความรู้ระหว่างมหาวิทยาลัยได้อย่างมีประสิทธิภาพ

**บัญชีใน migrate.py:** ผู้ส่ง `student2@uniresearch.ac.th`; ผู้เขียน `student2@uniresearch.ac.th`; ที่ปรึกษา `advisor2@uniresearch.ac.th`; ผลตรวจ `approved`

## การใช้ในกรณีทดสอบ

- ตัวเรื่องทั้ง 4 มาจากต้นทาง ส่วนชื่อที่เติมวงเล็บ “สำเนา…” หรือ “ฉบับ…สำหรับทดสอบ” เป็นสำเนาที่ผู้เตรียมข้อมูลต้องสร้างเพื่อแยกกรณีส่งใหม่ แก้ไข ลบ และไม่มีไฟล์ ไม่อ้างว่ามีชื่อเต็มพร้อมวงเล็บนี้ใน migration
- ต้นทางสร้างผลตรวจเป็น approved ทั้ง 4 เรื่อง แต่กรณีทดสอบต้องเตรียมบางสำเนาเป็นรอตรวจหรือส่งกลับแก้ไขก่อนเดินขั้นตอน จึงต้องตรวจเงื่อนไขตั้งต้นราย TC และไม่ใช้ผลจาก migration โดยไม่ปรับสถานะ
- ต้นทางใช้บัญชี student1/student2 และ advisor1/advisor2 ของข้อมูลตัวอย่าง ขณะที่เอกสารปัจจุบันใช้บัญชีจาก CSV ตามคำขอ การผูกงานกับนรงศ์ศักดิ์ กิติกร อุษณีย์ หรือวรเชษฐ์เป็นการเตรียมข้อมูลบนสำเนาฐานทดสอบ ไม่ใช่หลักฐานความเป็นผู้แต่งจริงของบุคคลเหล่านี้
- เลขผู้ใช้ เลขผลงาน เลขหมวดหมู่ ตัวนับ และวันที่ใน Test Cases เป็น mapping/ค่าควบคุมของฐานทดสอบตามแผน ต้องตรวจจาก response หรือค้นด้วยชื่อเต็มก่อนใช้กับฐานที่นำเข้าจริง ไม่ถือว่าเรียก migration แล้วจะได้ id เดียวกันเสมอ
- คำค้นเฉพาะ publickeyword/pendingsecret/ranktitle และค่าจาก AI mock เป็นตัวควบคุมการทดสอบที่ต้องเตรียมเพิ่ม ไม่ใช่ชื่อหรือคำสำคัญต้นฉบับจากงานวิจัย
