บทคัดย่อ

การวิจัยนี้มีวัตถุประสงค์เพื่อศึกษาพฤติกรรมการใช้สื่อสังคมออนไลน์และผลกระทบที่มีต่อการตัดสินใจซื้อสินค้าและบริการของวัยรุ่นในเขตกรุงเทพมหานคร โดยใช้ระเบียบวิธีวิจัยเชิงปริมาณ (Quantitative Research) ประชากรกลุ่มตัวอย่างคือวัยรุ่นอายุ 15-22 ปี จำนวน 400 คน เครื่องมือที่ใช้ในการวิจัยคือแบบสอบถามออนไลน์ สถิติที่ใช้ในการวิเคราะห์ข้อมูลได้แก่ ค่าความถี่ ร้อยละ ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน และการวิเคราะห์การถดถอยพหุคูณ (Multiple Regression Analysis)

ผลการวิจัยพบว่า กลุ่มตัวอย่างส่วนใหญ่ใช้เวลาบนสื่อสังคมออนไลน์เฉลี่ย 4-6 ชั่วโมงต่อวัน โดยแพลตฟอร์มที่ได้รับความนิยมสูงสุดคือ TikTok (ร้อยละ 45) รองลงมาคือ Instagram (ร้อยละ 30) ปัจจัยที่มีอิทธิพลต่อการตัดสินใจซื้ออย่างมีนัยสำคัญทางสถิติที่ระดับ .05 ได้แก่ การรีวิวจากผู้ใช้งานจริง (User-generated content) และอิทธิพลของบุคคลที่มีชื่อเสียง (Influencer marketing) นอกจากนี้ยังพบว่ามีความสัมพันธ์เชิงบวกระหว่างระยะเวลาการใช้งานสื่อสังคมออนไลน์กับความถี่ในการซื้อสินค้าออนไลน์
