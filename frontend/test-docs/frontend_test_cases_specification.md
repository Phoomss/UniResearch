**ระบบคลังข้อมูลวิทยานิพนธ์ งานวิจัย และโครงงานของมหาวิทยาลัย (UniResearch)**
**จัดทำโดย:** Sommai Supawong (Senior Tech & QA Lead)

---

## ส่วนที่ 1: ภาพรวมการทดสอบ (Overview)

### 1.1 วัตถุประสงค์ (Objectives)
เอกสารฉบับนี้จัดทำขึ้นเพื่อระบุกรณีทดสอบ (Test Cases) สำหรับส่วนหน้าบ้าน (Frontend) ของระบบ UniResearch ที่พัฒนาด้วย Next.js โดยเน้นการทดสอบ UI/UX, การเชื่อมต่อ API (BFF), การจัดการ State, การควบคุมสิทธิ์ (RBAC) ระดับหน้าจอ, Accessibility (a11y), และกระบวนการทำงานหลักแบบ End-to-End ผ่านเครื่องมืออย่าง Playwright

### 1.2 ขอบเขต (Scope)
* **ครอบคลุมฟังก์ชันหลัก:** การจัดการบัญชี, การส่งผลงานวิจัย, การตรวจสอบและอนุมัติ, การค้นหาและการทำงานของ RAG Chatbot, การดาวน์โหลด, และการจัดการแดชบอร์ด
* **ไม่ครอบคลุม:** การทำงานเชิงลึกของฝั่ง Backend (FastAPI) และ Database (PostgreSQL)

### 1.3 สมมติฐาน (Assumptions)
* ระบบ Backend ทำงานได้ปกติ หรือมีการใช้ Mock Service Worker (MSW) เพื่อจำลอง API Response
* ข้อมูล Fixture สำหรับการทดสอบถูกจัดเตรียมเรียบร้อยแล้ว (เช่น บัญชีทดสอบ, เอกสารทดสอบ)
* สภาพแวดล้อม: Next.js 16.2.12, Node 22, Playwright Chromium 1.62.1
